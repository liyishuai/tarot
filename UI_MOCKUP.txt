================================================================================
                              核心特性展示
================================================================================

✅ Web UI 替代了 CLI                    - 现代化的网页界面
✅ 牌义数据库 (78 张 × 2 方向)          - 不是硬编码牌阵，是硬编码牌义
✅ LLM Function Calling 创建牌阵         - 动态生成，不是预设
✅ 对话区域显示推荐                     - 清晰的对话历史
✅ UI 适配牌阵布局                      - 自动可视化布局
✅ 牌义优先于解读                       - 先显示含义，再 LLM 分析
✅ 移除文本搜索                         - 纯随机抽牌
